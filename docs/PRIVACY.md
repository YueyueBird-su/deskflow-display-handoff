# 隐私与本机数据

## 仓库内容

公开内容采用通用名称与占位符，不包含部署电脑的账号、网络地址、真实 Deskflow 电脑名称、个人绝对路径、SSH 连接信息、TLS 配对资料或设备序列标识。

演示 GIF 由绘图脚本生成，画面内只有虚构的通用窗口和标签，不来自截图／录屏。生成器不读取桌面、浏览器或账号设置。

## 运行时会在本机生成的文件

| 文件 | 包含的信息 | 保存位置 |
|---|---|---|
| `display-layout.json` | 本机显示接口、显卡／显示器标识、位置、分辨率和恢复模式 | Windows 助手目录 |
| `controller-state.json` | 切换阶段、错误和当前活动屏幕信息 | Windows 助手目录 |
| `controller-log.jsonl` | 模式切换结果、时间、屏幕摘要 | Windows 助手目录 |
| `media-key-probe.json` | 检测到的媒体功能键、时间、会话编号 | 手动运行按键检测工具的目录 |
| `deskflow-server.conf` | 实际部署时填写的电脑名称与规则 | Windows 助手目录 |

助手不记录普通文字输入；媒体键检测器只捕获其声明范围内的媒体／应用启动键。Hammerspoon 对编辑区的识别读取辅助功能元数据，不读取字段文字。

本助手没有上传日志或新增网络监听的代码。键鼠与剪贴板传输由独立安装的 Deskflow 按其自身配置完成；Hammerspoon 权限与偏好留在 Mac 本机。

## 分享自己的修改

`.gitignore` 已忽略布局、运行状态、探测结果、真实配置、备份、证书／密钥与环境文件。配置新机器后，提交前仍应检查暂存文件及 Git 历史，不要使用 `git add -f` 加入这些本机文件。

排障时可以分享经过清理的错误说明；完整日志可能包含屏幕硬件标识和本机路径，需要先去除这些内容。
